## 二、核心技术标准规范

### 2.1 碳排放核算标准体系

#### 2.1.1 核算边界与范围

**核算边界**：
- 适用于钢铁联合企业
- 包括：矿山、烧结、球团、焦化、炼铁、炼钢、轧钢等主要工序
- 不包括：矿山开采、固废处理处置

**温室气体种类**：
- 二氧化碳（CO₂）— 主要核算对象
- 甲烷（CH₄）— 辅助核算
- 氧化亚氮（N₂O）— 辅助核算

#### 2.1.2 排放源分类

| 排放类别 | 排放源 | 核算方法 |
|----------|--------|----------|
| **化石燃料燃烧排放** | 焦炭、焦粉、煤、煤气、柴油、重油等 | 物料平衡法/实测法 |
| **工业生产过程排放** | 熔剂脱碳、石灰石分解、轧钢过程 | 物料平衡法 |
| **净购入电力隐含排放** | 外购电力 | 排放因子法 |
| **净购入热力隐含排放** | 外购蒸汽/热水 | 排放因子法 |

#### 2.1.3 关键排放因子

| 燃料类型 | 排放因子 | 单位 |
|----------|----------|------|
| 焦炭 | 3.04 | tCO₂/t |
| 焦粉 | 3.04 | tCO₂/t |
| 烟煤 | 2.66 | tCO₂/t |
| 无烟煤 | 2.54 | tCO₂/t |
| 柴油 | 3.10 | tCO₂/t |
| 高炉煤气 | 1.570 | tCO₂/万m³ |
| 转炉煤气 | 2.200 | tCO₂/万m³ |
| 电力（华中电网） | 0.5810 | tCO₂/MWh | 2022年度数据，2024年12月发布 |

#### 2.1.4 碳排放量计算公式

```
碳排放总量 = Σ(化石燃料消耗量 × 排放因子 × 碳氧化率) + 过程排放 + 净购入电力排放

其中：
- 焦炭燃烧排放 = 焦炭消耗量 × 3.04 × 98.5%
- 电力排放 = 外购电量 × 0.5810（华中电网因子，2022年度数据）
```

### 2.2 MRV（监测-报告-核查）体系

#### 2.2.1 监测要求

| 数据类别 | 监测方法 | 监测频率 |
|----------|----------|----------|
| 活动水平数据 | 实测法/物料平衡法 | 连续/月度 |
| 排放因子 | 实测法/缺省值 | 年度 |
| 生产数据 | 台账记录 | 日度/月度 |
| 计量器具 | 定期校准 | 按检定周期 |

#### 2.2.2 报告要求

| 报告类型 | 报告周期 | 提交时限 |
|----------|----------|----------|
| 月度存证 | 月度 | 月结束后40日内 |
| 年度排放报告 | 年度 | 每年3月31日前 |
| 补充数据报告 | 按需 | 主管部门要求 |

#### 2.2.3 核查要求

- 核查机构：经认可的第三方核查机构
- 核查周期：每年一次
- 核查内容：数据完整性、真实性、准确性
- 核查结论：建立核查资料包，包含现场照片、台账凭证、计算过程

| 铝冶炼 | 电解铝、氧化铝 | ~200家 |

#### 配额分配方法

**基于碳排放强度控制法的免费配额分配**：

```
免费配额量 = 产品产量 × 行业基准值 × 修正系数

其中：
- 行业基准值：分工序/产品确定
- 修正系数：考虑铁矿石品位、热风温度等因素
```

**分工序基准值参考**（示例）：

|------|------|-------------|-------------|
| 烧结 | 烧结矿 | 0.169 tCO₂/t | 0.165 tCO₂/t |
| 球团 | 球团矿 | 0.082 tCO₂/t | 0.080 tCO₂/t |
| 焦化 | 焦炭 | 0.260 tCO₂/t | 0.255 tCO₂/t |
| 炼铁 | 生铁 | 1.330 tCO₂/t | 1.300 tCO₂/t |
| 炼钢 | 粗钢 | 0.210 tCO₂/t | 0.205 tCO₂/t |

## 六、国际规则与合规要求

### 6.1 欧盟碳边境调节机制（CBAM）

| 阶段 | 时间 | 要求 |
|------|------|------|
| 过渡期 | 2023.10-2025.12 | 仅报告，无需缴纳 |
| 正式实施 | 2026年 | 开始缴纳碳关税 |
| 全面实施 | 2034年 | 取消免费配额 |

#### CBAM覆盖的钢铁产品

| HS编码 | 产品描述 |
|--------|----------|
| 7207 | 钢铁半成品 |
| 7208-7212 | 扁钢、棒材 |
| 7213-7215 | 线材、钢筋 |
| 7301-7306 | 钢轨、型钢、管材 |

#### CBAM隐含碳计算方法

```
隐含排放 = 进口产品数量 × 嵌入式碳排放强度
嵌入式碳排放强度 = 默认值 或 生产企业实测值（需认证）

碳关税 = 隐含排放 × (EU碳价 - 原产国碳价)
```

## 十、调研结论

### 10.1 政策趋势总结

1. **监管趋严**：钢铁行业2025年正式纳入全国碳市场，MRV体系全面建立
2. **标准完善**：核算指南、核查指南、配额分配方案相继落地
3. **成本传导**：碳价上涨趋势明确，降碳成为企业核心竞争力
4. **国际接轨**：CBAM倒逼企业建立全生命周期碳管理能力
5. **数字赋能**：政策明确支持AI、大数据在碳管理中的应用

### 10.2 企业应对建议

| 短期（1年内） | 中期（1-3年） | 长期（3-5年） |
|--------------|--------------|--------------|
| 完善碳核算基础 | 建立能碳协同管控平台 | 构建产品碳足迹体系 |
| 健全MRV体系 | 开展碳交易能力建设 | 布局氢冶金技术 |
