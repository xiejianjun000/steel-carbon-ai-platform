# 冷钢碳排放AI平台 - 测试文档

## 测试目录结构

```
tests/
├── unit/
│   ├── carbon-calculator.test.js    # 碳核算算法单元测试
│   └── emission-factor.test.js      # 排放因子测试
├── integration/
│   └── api.test.js                  # API集成测试
└── README.md                        # 测试说明
```

## 测试环境要求

- Node.js >= 18
- Jest 测试框架（已包含在依赖中）

## 安装测试依赖

```bash
# 在项目根目录安装测试依赖
cd steel-carbon-ai-platform
npm install jest @jest/globals --save-dev
```

## 运行测试

### 运行所有测试

```bash
npm test
```

### 运行单元测试

```bash
npm test -- tests/unit/
```

### 运行集成测试

```bash
npm test -- tests/integration/
```

### 运行特定测试文件

```bash
npm test -- tests/unit/carbon-calculator.test.js
```

### 使用Mock模式运行（无需启动服务）

```bash
MOCK_MODE=true npm test
```

## 预期测试结果

### 碳核算算法测试

根据提供的活动数据，预期月度碳排放量约为：

- 燃料排放：~270,000 tCO₂（约70-80%）
- 过程排放：~19,000 tCO₂（约5-15%）
- 电力排放：~463,000 tCO₂（约15-20%）
- **总计**：约300,000-310,000 tCO₂

### 年度碳排放量

基于月度数据推算，年度碳排放量约为：

- **3,600,000 - 3,720,000 tCO₂**（月度均值 × 12）

## 测试注意事项

1. **单位转换**：焦炭消耗量输入为"万吨"，计算时需注意单位转换
2. **回收抵扣**：高炉煤气等回收能源使用负值表示
3. **Mock模式**：CI/CD环境中使用`MOCK_MODE=true`运行，无需启动真实服务
4. **精度要求**：碳排放计算精度要求较高，使用`toBeCloseTo`进行浮点数比较
