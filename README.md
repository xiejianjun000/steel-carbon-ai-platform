# 冷钢碳排放AI智慧管理平台

## 项目概述

冷水江钢铁碳排放AI智慧管理平台，基于人工智能技术实现碳排放数据的智能采集、分析与报告生成。

## 主要功能

- 碳排放因子数据库管理
- 五大工序碳排放智能核算
- 政策标准知识库
- AI智能问答助手
- 碳排放报告自动生成

## 技术栈

- **前端**: React + TypeScript + Vite
- **后端**: Node.js + Express
- **AI Agent**: Python + LangChain
- **知识库**: 向量数据库
- **数据库**: PostgreSQL + Qdrant

## 标准依据

- GB/T 32150-2025《工业其他行业企业温室气体排放核算方法与报告通则》
- GB/T 32151.5-2026《温室气体排放核算与报告要求 第5部分：钢铁企业》
