## 1. 产品概述

### 1.1 产品愿景与定位

**产品愿景**：构建钢铁行业领先的AI驱动碳排放智慧管理平台，通过智能化手段实现碳排放全生命周期管理，助力冷水江钢铁有限责任公司（以下简称"冷钢"）实现碳管理数字化转型，降低合规成本，提升碳资产价值。

**产品定位**：面向长流程钢铁联合企业的企业级碳排放AI智慧管理SaaS平台，覆盖碳核算、碳监测、碳交易、CBAM合规、核查辅助、知识服务六大核心场景，以AI智能体技术为核心引擎，提供一站式碳管理解决方案。

### 1.2 目标用户与使用场景

| 用户群体 | 核心场景 |
|---------|---------|
| 企业管理层 | 碳排放总览、决策支持、配额履约跟踪 |
| 能环部/碳管理人员 | 碳核算、数据填报、月度/年度报告编制 |
| 生产运行部门 | 工序级碳排放监控、异常预警处置 |
| 财务部门 | 碳配额成本核算、碳交易资金管理 |
| 国际贸易部门 | CBAM合规申报、隐含碳排放量计算 |
| 外部核查机构 | 数据核查、MRV验证 |

### 1.3 核心价值主张

1. **效率提升**：通过AI自动核算替代人工填报，碳核算效率提升80%以上，月度报告生成时间从5天缩短至2小时
2. **风险防控**：实时监测与智能预警，提前发现碳排放数据异常，避免核查风险
3. **成本优化**：智能配额管理与履约策略推荐，降低碳履约成本，预计年节约15%~30%
4. **合规保障**：自动生成符合国家MRV标准和CBAM要求的申报文件，确保合规零遗漏
5. **决策支持**：基于历史数据的碳排放趋势分析与预测，支撑企业低碳转型战略决策

## 3. 功能需求清单

### 3.1 P0级功能（核心功能，第一期必须实现）

#### FR-P0-001：碳核算智能体

| 需求项 | 说明 |
|--------|------|
| 需求ID | FR-P0-001 |
| 需求名称 | 企业级碳排放自动核算 |
| 优先级 | P0 |
| 描述 | 基于冷钢实际生产数据，按照国家温室气体排放核算标准（GB/T 32150-2025），自动计算企业层级碳排放总量 |

**功能要点**：

1. **活动数据采集与管理**
   - 支持批量导入化石燃料消耗数据（煤、焦炭、焦炉煤气、高炉煤气、天然气等）
   - 支持导入过程排放相关数据（石灰石消耗量、白云石消耗量、生铁产量、粗钢产量等）
   - 支持导入净购入电力数据（各工序电表读数、外购电量结算单）
   - 提供标准化Excel模板，支持模板下载和数据校验
   - 数据校验规则：数值范围检查、逻辑一致性检查（如消耗量≤采购量）、必填项检查

2. **排放因子管理**
   - 内置国家排放因子库（依据最新发布的国家标准排放因子）
   - 内置行业排放因子（钢铁行业默认值、行业基准值）
   - 支持企业自定义排放因子（实测值优先）
   - 排放因子版本管理与更新记录
   - 排放因子来源标注（国标/行标/实测/默认值）

3. **碳排放计算引擎**
   - 化石燃料燃烧排放计算（基于低位发热量和含碳量，排放因子法）
     ```
     E_燃料 = Σ(AD_i × EF_i)
     其中：AD_i = 第i种燃料消耗量 × 低位发热量 × 含碳量 × 氧化率
           EF_i = 44/12（CO₂与C的分子量之比）
     ```
   - 过程排放计算（含碳原料分解）
     ```
     E_过程 = Σ(AD_j × EF_j × 44/44)
     ```
   - 净购入电力排放计算
     ```
     E_电力 = AD_电力 × EF_电网
     ```
   - 企业层级碳排放总量汇总
   - 计算过程全记录，支持计算步骤追溯

4. **工序级碳排放分解**
   - 按工序分解碳排放量：原料（烧结）→炼铁（高炉）→炼钢（转炉）→轧钢
   - 工序碳排放强度计算（tCO₂/t产品）
   - 工序碳排放占比分析

5. **报告自动生成**
   - 月度碳排放存证报告（PDF格式）
   - 年度碳排放报告（PDF格式）
   - 报告内容包含：排放总量、分源排放明细、工序排放分解、同比/环比分析
   - 报告模板可配置，支持自定义Logo、企业信息

**验收标准**：
- [ ] 能自动完成企业层级碳排放计算，结果与手工计算偏差≤0.5%
- [ ] 支持至少10种燃料类型、5种过程排放源的核算
- [ ] 月度报告生成时间≤10分钟（数据就绪后）
- [ ] 计算过程可追溯，每一步计算均有中间结果记录

| 需求项 | 说明 |
|--------|------|
| 需求ID | FR-P0-003 |
| 需求名称 | 碳配额管理与履约跟踪 |
| 优先级 | P0 |
| 描述 | 管理企业碳配额的收支、结余，跟踪履约进度，提供基础履约策略建议 |

**功能要点**：

1. **配额台账管理**
   - 免费配额记录（批次、数量、获取方式、有效期）
   - 拍卖配额记录（批次、数量、成交价、交易日期）
   - CCER抵消配额记录
   - 配额结余实时计算
   - 配额到期提醒（到期前30/15/7天提醒）

2. **履约进度跟踪**
   - 当前年度应清缴配额量 = 核算排放量 × (1 - CCER抵消比例)
   - 已清缴配额量跟踪
   - 配额缺口/盈余自动计算
   - 履约倒计时（距离履约截止日天数）
   - 履约状态指示灯（绿色=充足/黄色=关注/红色=缺口）

3. **碳价跟踪**
   - 全国碳市场（CEA）最新成交价
   - 碳价历史走势图（近1月/3月/6月/1年/3年）
   - 预估履约成本 = 配额缺口 × 当前碳价
   - 碳价预警（设置目标价位，达到时提醒）

4. **履约策略建议**
   - 基于当前配额余量和排放趋势，给出履约建议
   - 建议"购买配额"或"出售富余配额"的时机分析
   - CCER抵消比例优化建议

**验收标准**：
- [ ] 配额台账支持增删改查操作，数据准确率100%
- [ ] 履约进度实时更新，偏差≤0.1%
- [ ] 碳价数据更新频率≤1天
- [ ] 履约到期提醒准确触发

### 3.2 P1级功能（重要功能，第二阶段实现）

#### FR-P1-001：碳监测智能体 - 异常预警

| 需求项 | 说明 |
|--------|------|
| 需求ID | FR-P1-001 |
| 需求名称 | 碳排放异常智能预警 |
| 优先级 | P1 |
| 描述 | 基于历史数据和AI算法，自动检测碳排放数据异常并触发预警 |

**功能要点**：

1. **异常检测规则**
   - 阈值预警：排放量超过设定阈值时告警
   - 趋势预警：排放量连续上升/下降超过设定趋势时告警
   - 同比预警：排放量同比去年偏差超过设定百分比时告警
   - AI预测预警：基于AI模型预测排放趋势，提前预警

2. **预警分级**
   - 一级预警（蓝色）：轻微异常，提醒关注
   - 二级预警（黄色）：中等异常，需要排查
   - 三级预警（红色）：严重异常，需要立即处置

3. **预警处置**
   - 预警通知（站内消息、邮件、短信可选）
   - 预警处置流程（发现→分析→处置→闭环）
   - 预警处置记录与统计分析

4. **CEMS数据比对**
   - 烟气在线监测（CEMS）数据与核算数据比对
   - 偏差分析报告自动生成
   - 偏差超过阈值时自动告警

**验收标准**：
- [ ] 异常检测准确率≥85%（误报率≤15%）
- [ ] 预警通知延迟≤10分钟
- [ ] 支持至少4种预警规则类型
- [ ] 预警处置闭环率≥95%

## 8. 风险与依赖

### 8.1 技术风险

| 风险项 | 风险等级 | 影响 | 缓解措施 |
|--------|---------|------|---------|
| AI模型准确率不达标 | 高 | 知识问答、异常预警功能效果不佳 | 预留调优时间；准备规则引擎作为降级方案；逐步优化知识库质量 |
| 历史数据质量差 | 高 | 核算结果不准确、预测模型偏差大 | 上线前进行数据清洗；建立数据质量管理机制；支持手动修正 |
| 企业内部系统对接困难 | 中 | 数据自动采集无法实现，依赖手动导入 | 采用阶段性对接策略，优先对接EMS；预留手动导入通道 |
| 系统性能不达标 | 中 | 大数据量下响应慢 | 性能测试前置；数据库优化；合理的数据分页和缓存策略 |
| CBAM规则变化频繁 | 中 | 合规功能需要频繁更新 | 模块化设计，规则与代码分离；建立政策跟踪机制 |
